The sheet auto-fills with active orders (not Completed/Cancelled) whose Expected Delivery Date is tomorrow — same rule as the Delivery Planner's "Tomorrow" bucket — so you usually shouldn't need to type Customer/Material/Finish/Qty by hand; those rows get a faint blue tint (not printed) so you can tell them apart from blank ones. Remarks is always left blank, even on auto-filled rows, for manual entry. Click 🔄 Refill from Tomorrow's Plan any time to re-pull the latest data (this replaces everything currently on the sheet). You can still edit any pre-filled cell, or type a new Customer Name from scratch and pick from the suggestions — Material Name then only suggests materials that customer has actually ordered, and Finish / Surface only suggests finishes seen for that customer + material. If a customer has more than one material, pick the first, type a comma, and it'll suggest the remaining ones — same trick works for multiple finishes. Use the 🎨 swatch on a row to highlight it any color (✕ clears it) — the color prints too. Long text wraps instead of getting cut off when you print. Click 🖨 Print when ready — it's formatted for A4 landscape.
